DEPLOYMENT ARCHITECTURE:
================================================================================

Browser (HTTPS:443)
    ↓
Nginx (Reverse Proxy)
    ↓
Node.js Express App (Port 5000) - systemd managed
    ↓
PostgreSQL Database (Port 5432)

Key Components:
  • Process Manager: systemd service (ra-school)
  • Web Server: Nginx (comes with Hestia)
  • Runtime: Node.js 20.x
  • Database: PostgreSQL 16
  • Control Panel: Hestia

================================================================================
QUICK DEPLOYMENT STEPS:
================================================================================

1. Run requirements check:
   $ deployment/check-requirements.sh

2. Run automated setup (one-time):
   $ sudo deployment/setup.sh

3. Install dependencies and build:
   $ npm ci --production=false
   $ npm run build

4. Initialize database:
   $ npm run db:push

5. Start service:
   $ sudo systemctl start ra-school

6. Enable SSL via Hestia Control Panel

7. Verify deployment:
   $ deployment/health-check.sh

For updates:
   $ deployment/deploy.sh
